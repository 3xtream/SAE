Panduan Deploy ke GitHub Pages (3 Menit)

① Buat Repository GitHub baru
Buka github.com/new → beri nama repo (misal: english-speaking-lab) → set Public → klik Create repository.

② Upload file speaking-lab.html
Di halaman repo → klik uploading an existing file → drag & drop file speaking-lab.html → klik Commit changes.

③ Aktifkan GitHub Pages
Settings → Pages → Source: Deploy from a branch → Branch: main → / (root) → Save.

④ Salin URL & Update Kode.gs
Tunggu ~1 menit. URL akan menjadi:
https://<username>.github.io/english-speaking-lab/speaking-lab.html Ganti nilai SPEAKING_LAB_URL di Kode.gs dengan URL ini → deploy ulang GAS.

⑤ Masukkan URL di kolom di atas → Selesai! 🎉

📖 Landasan Teori Ilmiah & Framework Metodologi
💡
Input Hypothesis (i+1)

Dipelopori oleh Stephen Krashen, teori ini menyatakan bahwa manusia mengakuisisi bahasa secara alami melalui paparan Comprehensible Input. Pelacakan aktivitas harian di sistem ini dirancang untuk memastikan Anda mendapatkan asupan input konstan guna membangun intuisi bahasa tanpa menghafal rumus tata bahasa struktural.

"We acquire language when we understand what we hear or read."
🕸️
Four Strands Framework

Prof. Paul Nation menegaskan bahwa pembelajaran bahasa yang efektif wajib menyeimbangkan empat porsi: Meaning-focused Input, Meaning-focused Output, Language-focused Learning, dan Fluency Development. Fitur Speaking Lab mengisi strand Output yang selama ini kurang terlatih.

Keseimbangan 4 aspek mempercepat pembentukan reflek bahasa.
⏱️
Parameter Otomatisasi WPM

Kecepatan membaca berkorelasi langsung dengan tingkat otomatisasi pemrosesan bahasa di otak. Target kelulusan bertahap (100→130→160 WPM) memaksa otak melompat langsung menangkap makna frasa secara holistik tanpa terjebak Mental Translation Trap.

Membaca cepat memotong proses menerjemahkan di dalam pikiran.
🧠
Spaced Repetition System (SRS)

Menggunakan algoritma penjarangan waktu untuk melawan kurva lupa. Fitur Flashcard interaktif secara otomatis memfilter kosa kata yang belum dikuasai agar diulas kembali tepat sebelum memori otak melupakannya, menghemat waktu belajar hingga 80%.

Mengunci ingatan jangka pendek menjadi retensi permanen.
Phase 1: Foundation Checklist (Target: 100 WPM)
Kondisi Mutlak Kelulusan Fase 1: Wajib terpenuhi seluruhnya secara objektif sebelum membuka materi Fase 2.
  • Akumulasi kosakata mencapai target dasar awal (300 - 400 Kata).
  • Kecepatan membaca stabil minimal pada target kelulusan 100 WPM.
  • Durasi input harian konsisten 20-30 menit tanpa bolos.
  • Penguasaan struktur kalimat dasar subjek-predikat tanpa hambatan arti kata.
  • Pembentukan kebiasaan harian (Habit Streak) terbentuk stabil di bulan pertama.
Phase 2: Expansion Checklist (Target: 130 WPM)
Kondisi Mutlak Kelulusan Fase 2: Fokus ekspansi struktural implisit dan penguatan auditori teks.
  • Akumulasi kosakata ekspansi tercapai (800 - 900 Kata).
  • Kecepatan membaca naik stabil menembus target kelulusan 130 WPM.
  • Buku bergradasi level A1+ / Graded Readers diselesaikan secara tuntas.
  • Pengenalan otomatis terhadap transisi tenses dasar (past, present, future).
  • Sesi peninjauan Flashcard mandiri dilakukan minimal 3 kali seminggu.
Phase 3: Activation Checklist (Target: 160 WPM)
Kondisi Mutlak Kelulusan Fase 3: Kriteria penentu kesiapan transisi aman dari input menuju area output terkontrol.
  • Akumulasi kosakata aktivasi tercapai (1200 - 1300 Kata).
  • Kecepatan membaca mencapai performa tinggi pada target kelulusan 160 WPM.
  • Protokol Reading Aloud berjalan harian untuk aktivasi otot organ wicara.
  • Mampu menangkap makna satu paragraf penuh tanpa melakukan translasi mental.
Phase 4: Mastery Checklist
Evaluasi Kelulusan Akhir Program (Mastery): Parameter keberhasilan total program akuisisi bahasa otomatis.
  • Akumulasi kosakata tingkat mahir tercapai (1800 - 2000 Kata).
  • Sesi praktek konversasional aktif berjalan lancar tanpa lag perumusan gramatikal.
  • Mampu memproduksi tulisan jurnal esai opini pendek secara natural.
  • Kelulusan total dari seluruh rangkaian kurikulum akselerasi 1 tahun.
